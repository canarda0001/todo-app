# 🚀 Next.js Todo App

Modern, hızlı ve responsive bir görev yönetim (Todo) uygulaması. Next.js ve React kullanılarak geliştirilmiştir.

## 🛠️ Kullanılan Teknolojiler

- **Çerçeve (Framework):** Next.js (App Router)
- **Kütüphane:** React
- **Dil:** TypeScript / JavaScript
- **Stillendirme:** Pure CSS (CSS Variables)

## ✨ Özellikler

- 📝 **Görev Yönetimi:** Yeni görev ekleme, tamamlandı olarak işaretleme ve silme.
- 🎯 **Filtreleme:** Tümü, Aktif ve Tamamlanan görevleri filtreleme.
- 🧹 **Toplu Temizlik:** Tamamlanan görevleri tek tıkla silme.
- 💾 **Kalıcı Hafıza (LocalStorage):** Sayfa yenilense bile görevlerin ve tema tercihinin korunması.
- 🌙 **Karanlık / Aydınlık Mod:** Gece ve gündüz kullanımına uygun tema seçeneği.
- 📱 **Responsive Tasarım:** Mobil ve masaüstü cihazlarla tam uyumlu arayüz.
